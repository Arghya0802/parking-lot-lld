# Parking Lot LLD and Concurrency

A practical learning module for designing a Parking Lot system using low-level design principles, Java examples, SOLID, design patterns, and concurrency controls.

## Read the guide

- **Interactive guide:** [`parking-lot-lld-concurrency.html`](./parking-lot-lld-concurrency.html)
- **Detailed notes:** [`parking-lot-lld-concurrency.md`](./parking-lot-lld-concurrency.md)

## Topics

- Requirements, invariants, domain modeling, and API design
- SOLID principles and pragmatic design patterns
- Thread safety, race conditions, mutexes, and semaphores
- Atomic variables and compare-and-set operations
- Optimistic and pessimistic database locking
- Idempotency, transactional outbox, and payment recovery
- Concurrent testing and production evolution

The guide uses Java 21+ for concrete examples while keeping the design principles language-neutral.
