⚡ Optimistic mode

  • Computes from an immutable snapshot.
  • CAS succeeds only if state is unchanged.
  • Conflicts retry with a strict bound.
  • Best when collisions are uncommon.

🔑 Pessimistic mode

  • Locks before reading and deciding.
  • One thread owns the transition.
  • Unlock uses finally, RAII, or context manager.
  • Best for short, consistently hot operations.
